# 控制台界面精简与 Grafana 发现

用户通过七条浏览器批注要求重做登录封面、删掉冗余提示、精简角色页，并给监控增加从集群发现。用户选择浅色集群拓扑封面。

## 界面方案

- 登录：保留蓝色品牌与浅色基调，以层叠集群节点、连线和留白替代六边形光晕插画。只保留产品名与“多集群，尽在掌握”短标题，删除底部部署说明。
- 概览：移除更新时间和全局页头刷新按钮；保留连接失败时的重新连接与现有数据加载行为。
- 角色：每个对象以一个权限摘要展示，完整动作和作用范围在点击后查看。帮助文字收进按需查看的说明，编辑、复制、删除和授权表单保持可用。
- 镜像仓库：成功测试仅保留状态标签；错误原因仍可查看。
- 监控：增加“从集群发现”，默认扫描当前集群全部授权命名空间，可手动输入命名空间缩小范围，扫描 Grafana Service/Ingress 候选；展示来源与可用地址，点击添加预填已有表单，由用户核对保存。

## 方案取舍

继续保留全部说明会无法解决文字密集问题；完全隐藏权限明细会妨碍核对授权。采用摘要加按需展开。封面用户选择浅色拓扑，极简纯品牌或深色插画不采用。

## 约束与验证

不引入依赖，不改变授权范围，不读取 Secret，不修改现有 Token。扫描应区分失败与无候选；ClusterIP 内部地址不能冒充外部浏览器可达地址。用专门的行为测试验证发现、权限与异步状态；用构建与浏览器验证布局、交互和响应式显示。
